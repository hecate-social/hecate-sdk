    Delivery artifact templates for code generation.

    Generates CI/CD workflows, Dockerfiles, release workflows, and package scripts based on plugin type (in_vm or container).

    Also provides bump_version/1 for updating version strings across manifest.json, .app.src, and rebar.config.
